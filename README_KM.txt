Hay Day Farm Assistant — Android source project

គម្រោងនេះជាកម្មវិធីជំនួយរៀបចំផែនការ និងរំលឹក។ វាមិនមាន bot ដែលបញ្ជា Hay Day ដោយស្វ័យប្រវត្តិទេ។

បង្កើត APK:
1. ដំឡើង AndroidIDE ឬកម្មវិធី IDE Android ដែលគាំទ្រ Gradle លើ Android។
2. Extract ZIP នេះ។
3. បើក folder HayDayFarmAssistant ជា Gradle project។
4. Sync/Build Project។
5. ជ្រើស Build APK (debug) ហើយដំឡើង APK ដែលបានបង្កើត។

តម្រូវការ:
- Android SDK Platform 35 (ឬកែ compileSdk/targetSdk ទៅ SDK ដែល IDE មាន)
- JDK 17
- Gradle plugin 8.6.1 ដែល IDE អាចទាញយកបាន។

ចំណាំ:
- ZIP នេះមាន source code សម្រាប់ build APK មិនមែនជា APK ដែលបាន compile រួចទេ។
- មិនចាំបាច់ប្រើ root ឬផ្ដល់ Accessibility permission។
- សាកល្បងលើទូរស័ព្ទរបស់អ្នក ហើយកុំដំឡើង APK ពីប្រភពមិនស្គាល់។
